# Thallusin biosynthetic potential across the prokaryotic tree of life

This repository contains the analysis scripts and associated input/output files used to investigate the distribution of putative thallusin biosynthetic genes across species-level representative prokaryotic genomes from mOTUs-db v4.0.

## Overview

The analysis is based on the pre-computed set of 124,295 species-level representative genomes from mOTUs-db v4.0 ([Dmitrijeva et al., 2025](https://doi.org/10.1093/nar/gkae1004)). As part of the original mOTUs-db processing, genomes were taxonomically classified using GTDB R220 with GTDB-Tk v2.4.

To map the thallusin biosynthetic potential, protein-coding genes were predicted using Prodigal v2.6.3. and searched with MMseqs2 (`easy-search mode`) against nine target proteins (`ebo_proteins/ebo.faa`) associated with thallusin biosynthesis:

- EboA–F from *Maribacter stanieri* DSM 19891 (RefSeq accession GCF_900112245.1)
- Ino1, Epi1, and Epi2 from *Saccharomonospora* sp. CNQ-490 (RefSeq accession GCF_000527075.1)

The main R analysis (`scripts/thallusin_analysis.R`) takes the MMSeqs2 output and identifies putative thallusin biosynthetic genes and co-localized gene clusters, summarizes their taxonomic distribution, and generates figures and iTOL input files.

A second R script (`scripts/plot_environment_distribution.R`) combines available mOTUs v4.0 environmental annotations ([Dmitrijeva et al., 2025](https://doi.org/10.1093/nar/gkae1004)) with additional NCBI BioSample metadata for isolate genomes and generates the environmental distribution analysis.

## Input data

### mOTUs v4.0 representative genome metadata

The file `input_tables/mOTUs_v4.0_genome_summary_representatives.tsv.gz` contains the summary of species-level representative genomes used in this analysis.

It was generated from the mOTUs v4.0 genome-summary table downloaded from the https://mOTUs-db.org web interface by selecting only rows (genomes) that are representatives of species-level mOTUs clusters.

Of note, protein FASTA files were unavailable for two representative genomes, which were thus excluded from the downstream MMseqs2-based analysis, resulting in 124,293 genomes analyzed:

- `EREM23-1_SAMEA110646518_MAG_00000039`
- `EREM23-1_SAMEA2623601_MAG_00000045`

### mOTUs v4.0 sample metadata

The file `input_tables/mOTUs_v4.0_sample_metadata.tsv` corresponds to Supplementary Table 4 of the mOTUs-db publication and links mOTUs sample identifiers to BioSample accessions, studies, environmental categories, and source-sample links.

Source: https://doi.org/10.5281/zenodo.13325008

### NCBI BioSample metadata

For isolate genomes lacking environmental annotations in the mOTUs v4.0 sample metadata, additional metadata were retrieved from NCBI BioSample.

The script `scripts/download_ncbi_environment_metadata.py` extracts the NCBI assembly accession encoded in each mOTUs `GENO` genome identifier and queries the NCBI Datasets API for the corresponding genome record and linked BioSample. Relevant BioSample fields describing environmental or host origin are collected and standardized into a long-format table.

The resulting file is: `input_tables/mOTUs_GENO_NCBI_biosample_environment.tsv`

It contains, for each queried genome, the mOTUs genome identifier, NCBI assembly accession, BioSample accession, the original BioSample attribute name and value, and a harmonized attribute category used in the downstream environmental classification.

The raw NCBI metadata are not directly assigned to broad habitat classes at this stage. Instead, `plot_environment_distribution.R` maps the retrieved BioSample information conservatively onto the existing mOTUs v4.0 environmental vocabulary. These NCBI-derived annotations are only used when no original mOTUs v4.0 environmental annotation is available.

The generated table is included in the repository so that the downstream environmental analysis can be reproduced without repeating the NCBI queries.

## Reproducing the analysis

The analysis was run with **R v4.5.3**.

To recreate the Conda environment:

```bash
conda env create -f environment.yml
conda activate r_env
```

Run all analysis scripts from the repository root.

### 1. Thallusin biosynthesis gene analysis

```bash
Rscript scripts/thallusin_analysis.R
```

This script combines the mOTUs v4.0 representative-genome metadata with the MMseqs2 search results.

It:

- summarizes the presence of the nine target proteins per genome
- identifies genomes encoding for the core proteins EboB, EboC, EboE, and EboF
- detects clusters of co-localized target genes
- summarizes gene content and prevalence across taxonomic groups
- generates figures
- prepares GTDB R220 / iTOL visualization files

For calling putative thallusin biosynthetic gene clusters, a retained cluster must contain at least four unique target genes, with a maximum gap of six genes between consecutive target hits.

The main genome-level output is: `output_tables/thallusin_mOTUsDB_124293genomes_mmseqs2_thal_cluster.xlsx`

### 2. NCBI BioSample metadata retrieval

The NCBI metadata table included in this repository can be regenerated using:

```bash
python scripts/download_ncbi_environment_metadata.py
```

### 3. Environmental distribution analysis

```bash
Rscript scripts/plot_environment_distribution.R
```

This script reads the main output from `thallusin_analysis.R` and adds environmental source information.

Environmental annotations are assigned with the following priority:

1. existing mOTUs v4.0 environmental annotation
2. NCBI BioSample classification for genomes without an mOTUs annotation
3. no annotation

NCBI BioSample metadata are conservatively mapped onto the existing mOTUs v4.0 environment vocabulary before being combined with the original annotations.
